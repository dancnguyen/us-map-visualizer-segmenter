# US Map Visualizer and Segmenter
A simple app to visualize and segment the US map by geographic identifiers like city and zip code.

## Getting started

```bash
cd usmapvisualizersegmenter
npm install
npm run dev
```

See [usmapvisualizersegmenter/README.md](usmapvisualizersegmenter/README.md) for features, scripts and where the map data comes from.
